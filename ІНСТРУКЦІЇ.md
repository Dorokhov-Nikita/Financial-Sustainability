# Інструкції для запуску проекту "Financial Sustainability Assessment"

## Передумови
- Python 3.10+
- Node.js (для Live Server)
- Вільні портів: 5000 (Flask) та 8000 (Frontend)

## Швидкий старт

### 1. Відкрити VS Code
Перейти до папки проекту: `D:\Financial Sustainability`

### 2. Ініціалізація бази даних (перший раз)
```bash
python init_db.py
```

### 3. Запустити Flask Backend
Відкрити термінал та виконати:
```bash
cd backend
python -m flask --app app run
```

Backend буде доступний за адресою: **http://localhost:5000**

### 4. Запустити Frontend Server
Відкрити ще один термінал та виконати:
```bash
cd frontend
npx live-server --port=8000
```

Frontend буде відкритий за адресою: **http://localhost:8000**

## Робочий процес в додатку

### Головна сторінка (Home)
- Якщо ви не авторизовані - бачите пропозицію зареєструватися
- Якщо авторизовані - бачите привіт з ім'ям користувача

### Реєстрація (Sign Up)
1. Натиснути "Sign Up Now" на головній сторінці
2. Заповнити:
   - **Username**: Ім'я користувача
   - **Email**: Електронна пошта
   - **Password**: Пароль
3. Натиснути "Register"
4. **Автоматично авторизуватися** та повернутись на Home

### Авторизація (Login)
1. Натиснути кнопку на навігації
2. Ввести username та password
3. Натиснути "Login"

### Оцінювання (Assessment)
1. Обрати модель:
   - **Model 30**: Random Forest з 30 фінансовими показниками
   - **Model 50**: LightGBM з 50 фінансовими показниками

2. **Два способи введення даних:**

   **Спосіб 1: Ручне введення (Manual Input)**
   - Вводите значення для кожного показника
   - Натискаєте "Analyze"
   - Система аналізує дані та показує результат

   **Спосіб 2: Завантаження CSV (Upload CSV)**
   - Натискаєте "Upload CSV"
   - Вибираєте CSV файл з даними
   - Система аналізує перший рядок даних
   - Показує результат

### Результати (Results)
- **Risk Level**: Рівень ризику (High/Medium/Low)
- **Status**: Стан компанії (Bankrupt/Stable)
- **Probability**: Вірогідність банкрутства
- **Recommendations**: Рекомендації на основі результату

### Історія (History)
- Список усіх попередніх оцінок
- Дата та час оцінки
- Модель, яка була використана
- Результат прогнозу

### Аналітика (Analytics)
- Загальна кількість оцінок
- Кількість стабільних/банкротів
- Середня вірогідність
- Інформація про останню оцінку

### Довідник (Reference)
- Пояснення всіх 50 фінансових показників
- Описи формул та значень

## Рішення проблем

**Помилка "Port already in use"**
```bash
# Змінити порт Live Server
npx live-server --port=8001

# Або для Flask
flask run --port=5001
```

**CSS не завантажується**
- Натиснути Ctrl+F5 для повного оновлення браузера

**Помилка "Models not found"**
- Переконатися, що файли model_30.joblib та model_50.joblib в backend/saved_models/
- Якщо потрібно, перетренувати моделі:
  ```bash
  python train_models.py
  ```

**Помилка БД при першому запуску**
- Запустити: `python init_db.py`
